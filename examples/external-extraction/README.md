# 外部萃取格式範例（合成資料）

本資料夾示範 48 V 條款的 source、批次 input、固定 schema 與 result。
**這些範例識別碼不屬於你的資料庫，不能直接匯入。** 正式使用請從系統所選標準的「外部模型萃取（ChatGPT）」下載自己的包，再讓 ChatGPT 產生對應結果。

完整步驟見 [外部萃取指南](../../docs/EXTERNAL_EXTRACTION.md)，完整命令見 [Prompt](../../docs/CHATGPT_STANDARD_EXTRACTION_PROMPT.md)。

## 可直接匯入的完整成果

`complete.standard.json` 是 v0.3.2 新格式的合成示例，可以在「文件庫 → 匯入 ChatGPT 完整成果」直接預覽／匯入，不依賴本機 package_id。它僅包含合成電壓條文，不能當作真實標準。原有 input/result 示意檔仍受原包識別碼限制。
