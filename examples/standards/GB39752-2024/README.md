來源：使用者提供的《电动汽车供电设备安全要求》PDF，31 頁；本次不含任何產品資料。由 ChatGPT 依外網完整成果流程讀取並逐條拆解，原文保留簡體中文，萃取說明使用繁體中文。此資料集尚未由標準工程師覆核，不能直接作為認證結論。

## 下載與匯入

- [直接下載 GB39752-2024.standard.json](https://raw.githubusercontent.com/pcpcchen-coder/LocalAIforSPECheck/main/examples/standards/GB39752-2024/GB39752-2024.standard.json)
- [下載離線預覽頁 GB39752-2024-review.html](https://raw.githubusercontent.com/pcpcchen-coder/LocalAIforSPECheck/main/examples/standards/GB39752-2024/GB39752-2024-review.html)：下載後以 Edge 或 Chrome 開啟，能搜尋、依類型篩選並檢視原文。這是唯讀預覽；人工修改與確認歷程請在主系統記錄。
- [驗證報告](validation-report.json)

適用 **v0.3.2**，不需更新程式、安裝軟體或重新下載模型。

1. 開啟 Portable 工具，進入「標準文件庫」。
2. 按「匯入 ChatGPT 完整成果」，切換到「成果連結」。**不要貼在原始規範檔案的上傳連結欄位**。
3. 貼上下列網址；若公司允許上傳，也可切換成果檔案模式選擇 `.standard.json`。

```text
https://raw.githubusercontent.com/pcpcchen-coder/LocalAIforSPECheck/main/examples/standards/GB39752-2024/GB39752-2024.standard.json
```

4. 操作者填自己的名字；外部模型填 `ChatGPT（此對話，版本未標定）`；備註可填 `GB 39752-2024 試匯入，待人工核對原文與引用規範`。
5. 按「檢查並預覽」，預期 **172 區塊、498 項、152 項待處理**；涵蓋範圍為 complete。
6. 閱讀提示後按「匯入文件庫，開始人工確認」。匯入只是保存，仍是未確認文件。
7. 對照原 PDF，覆核條件、數值、例外與引用；先解決適用要求的待釐清項目，再進行文件人工確認。對純背景／定義可經人工確認後調整分類；不要把所有待處理項目直接當不符合。
8. 標準文件確認後，再上傳**本機產品文件**做比對。引用資料不足時保留待釐清，不能僅凭本次 JSON 證明產品合規。

若 `raw.githubusercontent.com` 被公司網路擋住，須改用公司允許且可直接下載的 HTTPS 位置；此流程無法使被阻擋的網域自動可用。成果網址必須回傳 JSON，不能是 GitHub 預覽頁、登入頁或 ChatGPT 對話頁。

完整保留封面、目次、前言、第1–8章、表1–6、附錄A及參考文獻。省略重複頁眉頁腳、空白頁文字與裝飾標誌。跨頁条文合併；位置同時記錄PDF頁序及印刷頁碼。表格以 `|` 分欄，保留表頭、註腳、單位；表2註b的平方根符號經原圖確認補回。文字字距及换行略有規整，未以產品推定補齊規範。

`complete` 表示這份附件的原文覆蓋完整，**不是語意已人工核准，也不是其引用文件已全部取得**。未提供的引用標準依 Prompt 列為 unresolved；沒有自行從其他網站或模型記憶補入。

## 人工覆核重點

| 條文 | 保留的差異或條件 | 建議確認方式 |
|---|---|---|
| 第1章 | 限EV供電設備；排除放電、自動充電、顶部接觸式充電等 | 先檢查產品適用性，不能只比數值相近 |
| 5.3.3.1、5.3.3.2、A.2 | 多種保護方案擇一、前級條件與免配例外 | 不把每個替代方案都列為必需 |
| 5.3.7 vs 7.1 | 濕熱「結束後30min內」用 `>`；「結束前2h」用 `≥` | 保留不同時點與嚴格性，不能合併成一筆 |
| 5.3.8.1、表4、7.3.7.1 | 正文直流1.4倍；表列1000VAC對應1415VDC等 | 未替標準裁決；測試方案由專業人員確認 |
| 5.3.7/5.3.8 vs 7.3.6/7.3.7 | 前者寫「非電氣連接」，後者寫「電氣連接的各獨立回路」 | 保留原文疑義，不自行補字 |
| 7.3.1.2 | 未充電插頭為 `<60V DC`，不是 `≤60V` | 與表2 DVC A分開核對 |
| 5.4、7.4、5.7、附錄A | 大量引用GB44263、GB/T18487等 | 應再取得指定引用文件，不能推測缺少的門檻 |

所有 criticality 均為 unknown：本標準沒有對萃取項目的差異嚴重度逐項分級。本次不把安全主題字詞自動當高風險；待取得產品規格與工程判斷後再評估。
