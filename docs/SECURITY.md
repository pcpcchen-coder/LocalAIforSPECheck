# 本機資料與安全邊界

## 使用邊界

此版本面向單人、同機操作，介面由 `127.0.0.1` 提供，模型也限於 loopback 位址。不要把 Uvicorn 綁到 `0.0.0.0`，不要建立網路轉發或反向代理讓他人直接使用。應用程式未提供帳號登入、部門權限或多租戶隔離。

本工具的前端不使用 CDN，執行時沒有遙測或雲端 API。安裝 Python 套件與下載模型可能需要網路；LM Studio／Bionic 自身是否有更新、診斷或外部連線行為，應另由 IT 核對。工具限制本機模型端點，並不等於整台電腦已建立網路隔離。

## Windows Portable 的執行與來源

可攜版的 Python、llama.cpp、模型及 DLL 都在解壓資料夾內執行；不安裝 Windows 服務，不修改系統 PATH 或登錄設定，不需管理員權限。首次需另行準備 GGUF；程式與模型都取得後，日常操作無需網路。下載模型時僅取得固定檔案，不傳送產品或標準內容。組件版本、SHA-256 與授權依發佈包的資訊及 [PORTABLE_COMPONENTS.md](PORTABLE_COMPONENTS.md) 核對。

「免安裝」不等於公司已允許執行。若公司使用 AppLocker、WDAC 或端點控管禁止外來執行檔，請提供 Release、組件資訊與檢查碼給 IT 評估核准；不要停用防毒、改安全策略或繞過系統提示。沒有公司核准時，可攜式打包本身不能消除這項限制。

模型及應用服務只提供本機介面。關閉瀏覽器不會結束背景運算；請使用 `Stop.bat`。啟動器只管理自己啟動的服務，不應以整批終止所有 Python 或模型程式的方式停止。

## 保存哪些資料

Portable 版在解壓根目錄使用 `data/` 與 `logs/`，原始碼版工作資料目錄預設為 `data/`。工作資料包含原始上傳文件、擷取文字、SHA-256、標準文件庫、產品項目、抽取修改歷程、分析快照、初篩與排除理由、結果、模型設定、覆核事件及 reports 中的歷次匯出。文件內容可能含供應商秘密、專利資料或個資，應按原文件等級處理。

- Portable 啟動時生成本機模型 API key，啟動器會使用 `data` 中的暫存 key 檔，正常停止時清除該檔。設定使用的 API key 仍在本機 SQLite 中明文保存，沒有使用 OS Keychain 或 Credential Manager。應用程式不將 key 回傳到設定查詢，也不放入比對快照或匯出。
- 在支援的 Unix／macOS 平台，程式會限制資料目錄及資料庫存取權限；這不等於加密。Windows 的資料夾 ACL 應由 IT 設定。
- 建議使用作業系統的磁碟加密、個人登入與螢幕鎖定。不要把工作資料置於所有人可讀的位置。
- `.gitignore` 排除預設資料夾、資料庫、日誌及備份。若改用自訂資料目錄，仍應主動檢查其位置，避免誤提交。

## 瀏覽器與模型介面

模型 URL 限於本機，禁止 HTTP 重導向與環境 proxy，降低意外將文件送出本機的風險。瀏覽器入口限制 Host；寫入請求檢查 Origin 及跨網站來源訊號。回應使用安全標頭、禁止快取並限制資源來源。

這些措施不是身份驗證。同一台電腦上可執行程式的其他使用者／惡意軟體，仍可能存取本機 API 或資料檔。具敏感資料的工作站應依公司端點政策管理。

## 文件內容與提示詞注入

文件、模型回應及覆核意見均作為資料顯示；HTML 輸出處理特殊字元，Excel 輸出避免把文件內容當成公式。模型不提供 shell、瀏覽器或系統操作工具，因此文件中的指令不會被直接當作系統命令執行。

但惡意／錯誤內容仍可能影響模型判斷，例如要求忽略某些條款、錯誤認證聲明或假測試數據。引述驗證只確認原文是否存在，不能判定原文是否真實。對外來文件應保留來源、版本與供應商簽核紀錄。

日誌可能包含模型路徑、檔名與錯誤訊息；除錯時先由文件擁有者檢視 `logs/`，不要直接將整個工作資料夾或未遮蔽日誌上傳公開 GitHub。

一般文件解析器仍有相容性與資源耗用風險。本工具設定單檔上限；不要將其視為防毒或任意不可信文件的隔離沙箱。套件更新由 IT 在備份與測試後執行。

## 覆核身份與稽核

覆核者姓名為自行輸入。歷史會保留確認、更正、重新開啟與版本號；版本檢查避免同時編輯覆寫，但沒有驗證覆核人的真實身份。

SQLite 檔案持有者可以直接修改資料，因此歷史不是不可竄改憑證。封存匯出也一樣：程式會保留每次檔案及 SHA-256，不透過介面覆寫舊檔，但雜湊與報告均保存在同機，並非第三方驗證或數位簽章。若用途涉及法規簽章或正式品質系統，應將成果送入公司已核准的簽核／文件管理流程。

## 備份與移除

1. 停止所有比對，退出本工具；Portable 版使用 `Stop.bat` 並等待停止。
2. Portable 版完整備份解壓資料夾；原始碼版備份整個工作資料目錄，包括 SQLite、uploads 與 reports。備份也可能包含金鑰。
3. 依原文件權限保存、加密與控管備份。
4. 還原前保持程式關閉，保留原資料夾備份，再以完整備份還原。

舊版 `/classic` 在介面移除文件只會將其移出目前專案，舊比對與原始檔仍保留，讓既有證據可以追溯。需要完整清除時由 IT 依保留政策處理資料目錄與所有備份。HTML、XLSX、JSON 匯出含原文內容，也必須一併納入分享、保存和刪除管理。
