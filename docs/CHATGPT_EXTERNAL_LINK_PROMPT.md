## 先確認範圍，再逐條處理

1. 確認名稱、版本、總頁數／章節、可讀範圍與缺頁。依閱讀順序建立原文區塊 `B00001`、`B00002`……，包括適用範圍、定義、要求、表格、註腳、測試方法、附錄及例外。`location` 註明實際 PDF 頁序、印刷頁碼／條款／表格位置；未知部分寫「未知」，不能捏造。
2. `text` 放完整原文轉錄，不能只放結論或摘要。保留原語言、數字、正負號、單位、比較符號、AC/DC、條件、註腳及表頭關係。表格可用明確逐列文字轉錄，但不要推測缺失儲存格。每區塊最多 12,000 字，宜約 500–1,500 字，避免切斷條文或表格列；跨區塊的條件用 context_evidence 連回原文。
3. 一個 `items` 項目只表達一項可獨立核對的要求；電壓、溫度、通訊、保護、試驗分開。保留應／宜／可／不得、適用對象、狀態、前置條件、時間、例外與合格標準。同一複合句可由多項共用完整引文；上下限屬同一範圍時可同項。
4. `kind` 只用 requirement（可核對的要求）、context（背景與定義）、unresolved（無法可靠解析）。`criticality` 只用 high／medium／low／unknown，且須說明原文依據；沒有依據用 unknown，不憑一般常識判高低。不要把「未知」寫成不符合。
5. 每個主引文 `quote` 必須逐字出現在該區塊的 `text`，不可用省略號拼接不連續文字。context_evidence 的引文也須逐字存在於同份成果指定的 block_id；最多 20 筆。數值等欄位一律字串；原文未記載就用空字串，不補值、不換算單位。
6. 數字看不清、OCR 有疑義、公式／圖示無法可靠轉錄、引用文件未取得時，保留可讀證據並標 unresolved；不要宣稱內容完整。不得把所有原文單純切段就當成完成的要求萃取，也不得用一條籠統項目代表整份文件。
7. 所有原文區塊都要保留，沒有可抽項目的區塊仍列出，items 可為空陣列。本機系統會把沒有被引文涵蓋的文字補成待處理項目；這只檢查成果內文字，不能證明原始 PDF 未缺頁。

## 唯一輸出格式

每份規範輸出一個 UTF-8 `文件名稱.standard.json`。不要混用舊版 `.result.json` 的批次格式，不要加入 document_id、package_id 或自行編造檔案 SHA-256。頂層與各物件只能含下面展示的欄位。

```json
{
  "schema_version": 1,
  "format": "local-specheck-standard-package",
  "standard": {
    "name": "合成示例規範",
    "source_url": "",
    "version": "",
    "category": "",
    "scope": "",
    "region": ""
  },
  "coverage": {
    "status": "complete",
    "description": "合成示例，僅一條原文；正式輸出請填實際頁數、讀取章節、表格與附錄範圍，並交代缺漏。"
  },
  "blocks": [
    {
      "id": "B00001",
      "location": "合成示例，第 1 條",
      "text": "額定直流電壓必須為 48 V。",
      "items": [
        {
          "name": "額定直流電壓",
          "parameter": "額定直流電壓",
          "value": "48",
          "unit": "V",
          "operator": "=",
          "conditions": "",
          "exceptions": "",
          "test_method": "",
          "criticality": "unknown",
          "criticality_basis": "原文未交代差異造成的風險嚴重度。",
          "quote": "額定直流電壓必須為 48 V。",
          "kind": "requirement",
          "context_evidence": []
        }
      ]
    }
  ]
}
```

standard.name 必填（240 字內），其餘 standard 欄位都是字串（各 5,000 字內）。source_url 填實際來源 HTTPS 連結，不含帳號、密碼、查詢金鑰或暫時存取 token；附件或無安全公開連結時填空字串。不要填成果下載網址充當原規範來源。

coverage.status 只有 complete 或 partial。只有確實讀完並保留整份文件可比對原文時才填 complete。任何未讀章節、缺頁、漏表格或未完成部分都填 partial，description（8,000 字內）列明已讀與未讀範圍、OCR／圖表限制。partial 成果只能預覽，不能正式匯入文件庫或開放給產品分析；不能只為了通過匯入而改成 complete。complete 也只是你的範圍聲明，仍須人工覆核。

每檔最多 16 MB、2,000 個區塊、20,000 個項目；每區塊最多 200 個項目。每個項目文字欄位最多 20,000 字。block.id 必須唯一，只用英文、數字、底線、連字號；location 必填且最多 500 字。
