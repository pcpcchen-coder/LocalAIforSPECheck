# Windows 免安裝版操作指南

適用 **Windows 10／11、64 位元 x64**。v0.3 的程式 ZIP 與模型分開提供：ZIP 內附 Python、全部執行套件、CPU 模型服務及必要 DLL；**不含 GGUF 模型**。初次另行準備模型後，即可單機離線使用，不必安裝 Python、LM Studio 或 Bionic。

## 第一次下載與啟動

1. 從 [最新 Release](https://github.com/pcpcchen-coder/LocalAIforSPECheck/releases/latest) 下載 **`LocalAIforSPECheck-Windows-x64.zip`**，或用 [ZIP 直接連結](https://github.com/pcpcchen-coder/LocalAIforSPECheck/releases/latest/download/LocalAIforSPECheck-Windows-x64.zip)。不要選 `Source code (zip)` 或綠色 Code 按鈕中的 ZIP。
2. 在 ZIP 按右鍵，選 **全部解壓縮**，放到自己可寫入的本機位置，例如「文件」中的 `規格比對工具`。不要在 ZIP 視窗內直接執行。
3. 進入 `LocalAIforSPECheck-Windows-x64`。確認能看見 `Start.bat`、`Stop.bat`、`Download_model.bat`、`Choose_model.bat`、`runtime`、`app`、`engine`、`models`。
4. 第一次雙擊 **`Download_model.bat`**，等待下載及 SHA-256 檢查完成。它會下載固定版本 **Qwen3.5-2B-Q6_K.gguf**，約 1.56 GB，顯示進度；已存在且檢查正確的模型不會重新下載。
5. 雙擊 **`Start.bat`**。等待模型載入與瀏覽器開啟；保留啟動視窗，不要連續重複啟動。
6. 依 [同仁操作指南](USER_GUIDE.md) 建庫、上傳產品、確認項目、初篩、比對與覆核。

第一次需要取得「程式 ZIP＋一份模型」，後續更新程式只需 ZIP，沿用已下載的 `models`。模型獨立連結、大小及 SHA-256 永久整理在 [models/README.md](../models/README.md)。

下載器使用 HTTPS、固定模型版本、大小及 SHA-256。下載中的 `.part` 不是完成模型；驗證成功後才放到正式檔名。若同名模型不符預期，工具會保留它並提示另移或重新命名，不會直接覆蓋。

## 無法在工具電腦上網時

1. 在允許下載的電腦，取得程式 ZIP 與 [模型下載頁](../models/README.md) 的 GGUF。
2. 依公司允許的搬移方式，把 ZIP 與模型複製到工具電腦。
3. 解壓程式，將完整 GGUF 放入 `models`；若只有此模型，一般不必另外選擇。
4. 可執行 `Download_model.bat` 驗證已放好的固定模型；正確檔案會直接沿用，不需網路。
5. 雙擊 `Start.bat`。日常抽取、分析、覆核及匯出都在本機執行。

熟悉命令列的同仁也可讓下載器驗證並複製既有檔案，完全不連網：

```bat
Download_model.bat --source "D:\Downloads\Qwen3.5-2B-Q6_K.gguf"
```

若舊版 v0.2 已有此模型，直接複製舊版 `models` 即可，不必下載第二次。選用其他模型請看下方換模型方式。

## 電腦需求與下載檢查

CPU 推論不需要 CUDA 或顯示卡驅動。建議首輪在 16 GB RAM、保留 10 GB 以上可用空間的辦公電腦驗收；這是餘裕建議，不是實測的硬性最低需求。模型、文件、報告與備份都會增加用量。Windows ARM、32 位元 Windows 與網路共用磁碟不是這份套件的支援目標。

ZIP 檢查碼以同版 Release 的 `SHA256SUMS.txt` 為準；模型檢查碼看獨立模型頁，兩者不是同一個值。

```powershell
Get-FileHash .\LocalAIforSPECheck-Windows-x64.zip -Algorithm SHA256
```

若公司也禁止執行外來 EXE，仍須取得既有端點政策允許；免安裝不會繞過 AppLocker、WDAC 或防毒管制。不需要管理員權限，也不修改系統 PATH、登錄或安裝 Windows 服務。

## 使用 ChatGPT 萃取標準

v0.3.1 起，可在標準文件的「查看／確認」中使用「外部模型萃取（ChatGPT）」。包內包含完整 Prompt、原文及批次 input，回傳 JSON 經原文核對後分批保存，收齊再套用。操作見 [外部萃取指南](EXTERNAL_EXTRACTION.md)。Portable 內已附所需功能，不必安裝額外套件；模型仍分開下載。

## 每天如何操作

1. `Start.bat` → 等待瀏覽器開啟。若沒有自動開啟，使用啟動視窗顯示的 `http://127.0.0.1:...` 網址。
2. 第一次先建立少量標準與產品，核對抽取品質；再增加文件庫。
3. 新介面依序操作「標準文件庫」「產品與分析」「相關標準」「風險與覆核」「匯出與追溯」。
4. 已確認的標準項目可重用；每次新產品仍須抽取、核對並確認。
5. 完成後停止工作，執行 `Stop.bat`。下次啟動工作資料仍在。

預設應用埠 8765，模型埠 1235；被占用時啟動器改選可用埠，不終止其他程式。模型連線由啟動器設定，不需要雲端帳號或 OpenAI API key。網址只對同一部電腦有效，交接請提供報告或完整備份。

舊版專案、覆核及合成示範從「開啟舊版專案」進入 `/classic`。示範不呼叫模型；只能熟悉操作，不能作為模型內容品質測試。

## 怎麼知道是否正在執行

執行現況顯示抽取、初篩或比對的目前階段、文件／項目位置、請求等待時間、最近模型回覆及近期事件。完成百分比只使用實際完成資料。

| 顯示情況 | 解讀與處理 |
|---|---|
| 0%，正在等待模型回覆 | 可能第一個請求尚未完成；查看階段及等待時間 |
| 工作位置／近期事件更新 | 工作者有實際進展，並不代表判定必然正確 |
| 本機狀態可更新，但久無模型回覆 | 只證明應用程式可回應；查看啟動視窗及 `logs/model.log` |
| 狀態連線中斷或過久未更新 | 畫面保留最後已知狀態；先恢復服務，再重查狀態 |
| 已要求停止但仍等待 | 目前請求需返回或逾時，後續才停止 |

Portable 單次請求預設最多 600 秒，不是整個分析的總時間限制。時間增加不是模型仍在運算的證明；系統不假造 token 速度或剩餘完成時間。

若關閉瀏覽器，服務仍可能執行。要停止請用 `Stop.bat`；若工作中途退出，重啟後查看已保存資料，再續跑未完成工作。搬移與備份前一定要先停止。

## 換用較大的模型

1. 取得內附 llama.cpp 版本支援的單一 GGUF 文字模型。請先依 [模型與驗收建議](MODELS.md) 確認架構、記憶體與實際工作品質。
2. `Stop.bat` 後，把 GGUF 放進 `models`，保留原檔名。
3. 雙擊 **`Choose_model.bat`**，輸入模型編號；直接按 Enter 可取消。
4. `Start.bat` 後，以代表性短文件驗證抽取、初篩、比對與速度，再增加工作量。

固定入門模型供流程驗證及初篩，不能以成功啟動推定能可靠判斷複雜例外。下載器只管理指定入門模型，不會覆蓋自選模型；更大的 GGUF 要自行取得。副檔名是 GGUF 不代表所有架構都能載入，此版也不自動合併分片模型或安裝 GPU 後端。

模型指紋隨分析保存；中斷工作須使用相符模型續跑。換模型要建立新分析，舊結果不會自動重新計算。更換模型名稱或內容後，請先處理未完成工作，避免無法續跑。

## 更新、備份與搬移

| 資料夾 | 內容 | 更新時怎麼做 |
|---|---|---|
| `data` | 文件庫、產品、資料庫、原始附件、分析、覆核、報告及模型選擇設定 | 完整複製，不能只搬 SQLite 檔 |
| `models` | 已下載的固定模型及自選 GGUF | 完整複製沿用；新版 ZIP 不含模型 |
| `logs` | 啟動及模型日誌 | 可保留排錯，分享前檢查敏感內容 |
| `app`、`runtime`、`engine` | 程式、Python、模型服務 | 使用新版 ZIP 的完整內容，不混用內部檔案 |

1. 舊版先停止工作，再 `Stop.bat`，等待服務停止。
2. 完整備份舊版資料夾，將新 ZIP 解壓到**另一個新資料夾**。
3. 把舊版**整個 `data` 及 `models`** 複製到新版相同位置。即使只用入門模型，也必須複製；v0.3 ZIP 不再附模型。
4. 啟動新版，確認模型選擇與資料。舊版專案到 `/classic` 查閱；新入口使用新版文件庫流程。
5. 在新版「標準文件庫」按 **「匯入舊版專案文件」**，選擇原專案並匯入。產品與標準沿用舊原檔，不必逐份重新上傳；相同內容及角色已在新版庫時重用。新匯入文件完成獨立項目抽取與確認後，才能參加新分析；舊比對與覆核仍保留在 `/classic`。
6. 瀏覽器顯示舊介面時按 `Ctrl+F5`。確認正常後封存舊版；不要同時操作兩份資料夾，避免資料分散。
7. 如需退回，使用升級前的完整備份；不要把已由新版寫入的資料庫直接交給舊程式使用。

搬到另一台相容的 Windows 電腦時，可在停止後複製整個資料夾。HTML／Excel／JSON 是報告，不等於含所有附件的可續作備份。機密文件、報告、日誌及備份不可上傳公開 GitHub。

## 遇到問題時

| 現象 | 處理方式 |
|---|---|
| 找不到啟動檔／runtime | 核對是否下載 Release 的 Portable ZIP，並全部解壓縮 |
| 提示缺少模型 | 執行 `Download_model.bat`，或把既有 GGUF 放入 `models` |
| 模型下載中斷 | 保留錯誤訊息後重試；不要把 `.part` 改名冒充完成模型 |
| 同名模型檢查失敗 | 先保留並移走或重新命名該檔，再下載；不要直接覆蓋可能是自選模型的檔案 |
| 無法寫入資料 | 將完整資料夾放到自己可寫入的本機位置 |
| 模型無法載入／記憶體不足 | 查看 `logs`；若剛換較大模型，停止後切回已驗證的入門模型 |
| Windows／公司防護拒絕執行 | 保留提示及 Release 來源，交由公司既有核准流程處理 |
| 大量待釐清 | 查看來源、抽取與模型警告；不要為降低待確認數量而改成符合 |
| 找不到舊資料 | 確認使用同一份完整 `data`，並到 `/classic` 查看舊版專案 |
| CPU 分析太久 | 先實測短文件；比較模式、關鍵性與產品分段數都會影響請求量 |

回報時提供版本、Windows 版本、記憶體、模型、操作步驟和錯誤文字；日誌先檢查內容。詳細來源與授權見 [元件文件](PORTABLE_COMPONENTS.md)。
